# Python_Practice & Semicondutor Data Analysis

Repositories 用於紀錄我的 Python 學習與資料分析歷程。

目前的學習目標除了熟悉 Python 語法，也希望逐步將 Python、NumPy、Pandas 與 Matplotlib 應用於工程與半導體製程資料分析，
並作為後續專題的基礎。

目前希望建立以下能力:

- Python 基礎程式設計

- Matplotlib 資料視覺化
- CSV / Excel 資料處理
- 工程實驗數據分析
- 半導體製程資料分析
